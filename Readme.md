# Grupo Meridiano

Frontend inmobiliario inspirado en las referencias entregadas: estética premium verde/crema, hero editorial, buscador, propiedades, contacto, trastienda y panel interno.

## Ejecutar

```bash
npm install
npm run dev
npm run build
```

## Vistas

- Inicio
- Comprar
- Alquilar
- Propiedades con filtros
- Contacto
- Trastienda / tasación
- Panel inmobiliario

Las imágenes de propiedades usan URLs de Unsplash para que el layout tenga contenido visual desde el primer arranque.
